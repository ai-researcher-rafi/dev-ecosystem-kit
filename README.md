# 🚀 dev-ecosystem-kit // Next-Gen AI & Automation Suite

The Ultimate Developer Suite containing Production-Ready Boilerplates, Tailwind UI Components, DevOps Automation Scripts, and Futuristic Google Gemini AI Agents.

Developed and maintained by **[Md Rafikul Islam](https://github.com)** (AI, Automation & Software Architect).

## 🌟 What's Inside?

### 🤖 01-boilerplates (Advanced AI & Core Frameworks)
- **gemini-autonomous-agent:** Multi-step agentic execution loop powered by Gemini 2.5 for autonomous reasoning and report generation.
- **gemini-context-scraper:** Advanced semantic parser that extracts raw web text data and generates analytical market intelligence summaries.
- **gemini-ai-assistant:** Secure Node.js & Express server layout integrated with Google GenAI API for streaming interactions.
- **node-express-api:** Enterprise-grade REST API base featuring production JWT authentication and secure middleware route shielding.

### 🎨 02-ui-components (Premium Interactive Dashboards)
- **cyberpunk-landing-page:** High-end Neon-Cyberpunk themed responsive landing page featuring smooth layouts and custom structural canvas enhancements.
- **ai-chat-interface:** Immersive full-screen dark-themed real-time chat window for fluid frontend-to-backend model streaming simulation.
- **tailwind-cards:** Responsive premium UI building blocks including customizable product drops and startup pricing tables.

### 🐳 03-devops-automation (Cloud Infrastructure & AI Tools)
- **gemini-git-shuttle:** Futuristic localized CLI script that reads git changes, asks Gemini to write smart commit messages, and automatically saves your work.
- **docker-compose-presets:** Multi-container configuration orchestrating the API server, localized state directories, and MongoDB securely in 1-click.
- **docker-presets & github-actions:** Production-ready multi-stage Dockerfiles and automated CI workflows testing Python/Node nodes on every push.

### 📑 04-essential-configs (Workspace Starters)
- Pre-configured `.gitignore` boilerplate templates for highly decoupled environments (Node, Python) and premium Markdown formats.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+) & Docker Desktop installed.
- Google Gemini API Key from Google AI Studio.

### Quick Launch Ecosystem
1. Clone the repository:
   ```bash
   git clone https://github.com/dev-ecosystem-kit.git
   ```
2. Setup your global parameters:
   ```bash
   cp 01-boilerplates/gemini-ai-assistant/.env.example .env
   ```
3. Fire up the entire ecosystem (API, AI Engine, Database) using Docker Compose:
   ```bash
   cd 03-devops-automation/docker-compose-presets
   docker-compose up --build
   ```
